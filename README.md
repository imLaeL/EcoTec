# EcoTec

## Descrição
EcoTec é um projeto web que explora a aplicação da Tecnologia da Informação (TI) no saneamento básico. O site apresenta os desafios do saneamento, como a TI pode ajudar, benefícios da implementação, limitações e desafios, além de uma conclusão sobre o futuro sustentável. Desenvolvido com foco em inovação, sustentabilidade e inclusão social.

## Funcionalidades
- **Introdução**: Apresenta o contexto do saneamento básico e o papel da TI.
- **Desafios do Saneamento Básico**: Lista os principais problemas enfrentados.
- **Como a TI Pode Ajudar**: Explica tecnologias como IA, automação, IoT e aplicativos.
- **Benefícios da Aplicação de TI**: Detalha vantagens como monitoramento em tempo real, análise de dados e gestão inteligente.
- **Desafios e Limitações**: Aborda barreiras como custos elevados, infraestrutura digital, capacitação técnica e integração com sistemas legados.
- **Conclusão**: Reflete sobre o impacto da TI no saneamento.
- **Equipe**: Apresenta os membros da equipe responsável pelo projeto.

## Tecnologias Utilizadas
- **HTML5**: Estrutura do site.
- **CSS3**: Estilização personalizada.
- **Bootstrap 5**: Framework para layout responsivo.
- **AOS (Animate On Scroll)**: Animações ao rolar a página.
- **JavaScript**: Interatividade básica.
- **Bootstrap Icons**: Ícones utilizados no design.

## Como Executar
1. Clone ou baixe o repositório para o seu computador.
2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` em qualquer navegador web moderno (Chrome, Firefox, Edge, etc.).
4. O site será carregado localmente e você poderá navegar pelas seções.

Não há necessidade de servidor local, pois é um site estático.

## Estrutura do Projeto
- `index.html`: Página principal do site.
- `assets/`: Pasta com recursos (CSS, JS, imagens, etc.).
  - `css/`: Arquivos de estilo.
  - `js/`: Scripts JavaScript.
  - `img/`: Imagens e ilustrações.
  - `vendor/`: Bibliotecas externas (Bootstrap, AOS, etc.).
